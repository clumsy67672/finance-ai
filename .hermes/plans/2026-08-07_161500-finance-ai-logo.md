# Finance-ai Logo & Tab Icon Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Create a brand logo for the Family Finance Chat Ledger app and surface it as the browser-tab favicon (and iOS home-screen icon), plus a small brand mark in the app header.

**Architecture:** Next.js 14 App Router serves icons via file conventions (`app/icon.svg`, `app/apple-icon.png`) — no manual `<link>` tags required. A single SVG "mark" (chat bubble + upward trend) is the source of truth; it is reused for the tab favicon, the iOS icon, and an inline React component in the header. Because the app runs in Docker, any new file under `app/` is baked into the image on `docker compose build`.

**Tech Stack:** Next.js 14 App Router, plain SVG, React (inline SVG component), `rsvg-convert` (librsvg) or ImageMagick for PNG export.

---

## Current context / assumptions

- Repo: `~/finance-ai`. App Router root: `app/`.
- No existing `app/icon.*`, `app/favicon.ico`, or `app/apple-icon.*`.
- `app/layout.tsx` exports `metadata` with title `Family Finance Chat Ledger` but no `icons`.
- Dashboard header (`app/(dashboard)/layout.tsx`) renders `<h1>Family Finance</h1>`; login (`app/(auth)/login/page.tsx`) shows the same title.
- User accesses the app from an iPhone over LAN (`http://192.168.1.11:4000`), so an iOS apple-touch icon is worthwhile.
- Brand palette already in use: slate-900 `#0f172a`, emerald-500 `#10b981` (progress bars), white. Logo should stay within this palette for cohesion.

## Logo concept

**Mark = chat bubble + upward trend line.** A rounded-square slate-900 tile holding a white speech bubble with an emerald upward polyline inside. Communicates "AI chat ledger that trends up." Must stay legible at 16×16 (tab) — keep it a single bold shape, no fine detail.

- Tab favicon: the mark only (no text) in `app/icon.svg`.
- iOS icon: same mark at 180×180 in `app/apple-icon.png`.
- Header: the mark (24px) + wordmark "Family Finance" via a React component.

---

## Proposed approach

1. Author one canonical SVG (`assets/logo.svg`) containing the mark + wordmark (source of truth / reusable).
2. Author `app/icon.svg` — the mark alone, optimized for tiny sizes.
3. Export `app/apple-icon.png` (180×180) from the mark SVG.
4. Create `components/brand-logo.tsx` (inline SVG React component) and drop it into the dashboard + login headers.
5. Rebuild + redeploy the Docker image; verify the tab icon via browser screenshot and the icon route via curl.

### Task 3: Add the iOS home-screen icon (`app/apple-icon.png`)

**Objective:** Provide a 180×180 apple-touch icon (Next.js requires PNG, not SVG, for `apple-icon`).

**Files:**
- Create: `app/apple-icon.png` (180×180)

**Step 1: Export PNG from the mark SVG**

First create a standalone mark SVG at 180×180 (reuse Task 2 geometry, scaled). Write `assets/icon-mark.svg`:

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 180 180" width="180" height="180">
  <rect width="180" height="180" rx="40" fill="#0f172a"/>
  <path d="M50 62h80a14 14 0 0 1 14 14v34a14 14 0 0 1-14 14H92L66 150v-14H50a14 14 0 0 1-14-14V76a14 14 0 0 1 14-14z" fill="#ffffff"/>
  <polyline points="62 113 88 84 110 102 130 74" fill="none" stroke="#10b981" stroke-width="13" stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

Then convert (prefer `rsvg-convert`, fall back to ImageMagick):

Run: `rsvg-convert -w 180 -h 180 assets/icon-mark.svg -o app/apple-icon.png`
If `rsvg-convert` missing: `convert -background none assets/icon-mark.svg app/apple-icon.png`
Expected: `app/apple-icon.png` exists, ~180×180.

**Step 2: Verify dimensions**

Run: `python3 -c "from PIL import Image; print(Image.open('app/apple-icon.png').size)"` (or `file app/apple-icon.png`)
Expected: `(180, 180)`

**Step 3: Commit**

```bash
git add assets/icon-mark.svg app/apple-icon.png
git commit -m "feat: add iOS apple-touch icon"
```

## Risks, tradeoffs, open questions

- **Docker rebuild needed:** new `app/` files only appear after `docker compose build web`; a hot restart alone won't pick them up. Plan includes the rebuild.
- **`rsvg-convert` may be absent** on the laptop — Task 3 provides an ImageMagick (`convert`) fallback; if neither exists, `npx --yes sharp-cli` can export PNG.
- **Favicon caching:** browsers cache favicons aggressively; verification may need a hard refresh / new incognito tab.
- **Open question:** should the login page also get the wordmark, or mark-only? Plan uses mark + wordmark for consistency; easy to trim if you prefer mark-only there.
- **Open question:** keep the existing "Chat Ledger" sub-label in the dashboard header, or drop it now that the logo implies the product? Plan drops it (replaced by `BrandLogo`); revert if you want it kept.
